## Required post-migration verification

The migration is not complete until:

1. every repository remains accessible under the same repository ID;
2. protected-main rules and required checks remain active;
3. GitHub App installations and repository access remain bounded;
4. Actions, release tags, attestations, Pages, webhooks, and upstream locks
   resolve under the new namespace;
5. current canonical references use `InfrastructureProductWorks`;
6. immutable historical evidence retains its original names and digests;
7. the Portfolio Provenance Gate is refreshed and attested from trusted
   `main`; and
8. no credentials, collaborators, visibility, bypass actors, cloud access,
   live data, spending, pilot authority, or production authority are added.
